# Global Agent Instructions for TryangleTech Project

<RULE>
## Auto-Update task.md

At the end of every successful task or set of user instructions, you MUST automatically update `task.md` (located in the project root) with a short, concise, bulleted list of the work you just completed.

Follow these rules for updating `task.md`:
1. Group tasks day-wise under a heading formatted as `## MMM DD, YYYY` (e.g., `## Aug 12, 2026`). 
2. If the current day's heading already exists, append your new tasks to it. If it doesn't exist, create it at the top of the list.
3. Keep the bullet points extremely brief and straight to the point (e.g., `- Updated Contact page hero text.`).
4. Do NOT ask the user for permission to do this. Consider it a mandatory final step before ending your turn.
</RULE>
